God-mode iris symbol tuning
===========================

Interactive tuner (preview + sliders + export):

  scripts/dev/god-symbol-tuner.html

  # from repo root (so Load from repo works):
  python3 -m http.server 8770
  open http://localhost:8770/scripts/dev/god-symbol-tuner.html

  - Pick symbols, drag dx/dy sliders (or arrow keys).
  - Copy export → paste into js/panopticon/god-symbol-offsets.data.js
  - Edits auto-save in browser localStorage.

Data file (paste target):

  js/panopticon/god-symbol-offsets.data.js

  dx / dy in SVG viewBox units (eye 0–100, center 50,50).

Preview in game:

  bash scripts/deploy/cloudflare.sh && bash scripts/dev/serve-local.sh
  → toggle god mode (Konami).
